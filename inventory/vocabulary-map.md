# Vocabulary Map

Cross-version terminology mapping. Generated by deterministic rules from inventory.csv.

## Per-version namespace dirs

| Concept | Canonical | open-design | desigjn-toolkit | gsd-design | WEBSITES | design-self-create |
|---|---|---|---|---|---|---|
| Per-version namespace | `.claude/` | _n/a_ | `.claude`, `refs` | `.claude`, `.mcp.json`, `exemplars`, `playbooks`, `quality`, `schemas` | `.mcp.json`, `prospects` | _n/a_ |

## Reusable workflow document

Canonical: `playbook` (procedural step-by-step) vs `skill` (SKILL.md frontmatter format).
Both terms used across versions; canonical pipeline uses both for distinct concepts.

## Reference site teardown

Canonical: `exemplar` (curated taste anchor with teardown markdown).
open-design uses `refs/` for cloned external repos. desigjn-toolkit uses `refs/`.
gsd-design uses `exemplars/`. design-self-create has actual produced sites used as exemplars.

## Quality enforcement spec

Canonical: `quality gate`. Spans `quality/`, `QUALITY*.md`, `LAUNCH*.md` across versions.
WEBSITES uses `LAUNCH-GATES.md`. gsd-design uses `quality/` dir + `QUALITY.md`.
desigjn-toolkit uses `.claude/memory/QUALITY_GATES.md`.

## Per-client working dir

WEBSITES: `clients/`, `prospects/`. design-self-create: per-site dirs (e.g., `distant-matter/`).
Canonical: `clients/<slug>/` for active engagements; `prospects/<slug>/` for pre-intake.

## Persistent memory

Canonical: `.claude/memory/`. desigjn-toolkit fully uses this.
Other versions use ad-hoc top-level docs (CLAUDE.md, ARCHITECTURE.md) instead.
